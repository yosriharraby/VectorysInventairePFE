  scripts/test-import-stock.xlsx

  Agents utilisés (présents dans VectorysDB sur YOSRI\SQLEXPRESS) :
    - AG001 → emplacements TEST-A01, TEST-A02
    - AG002 → emplacements TEST-B01, TEST-B02

  Contenu :
    TEST-A01 : US-T001 (x2) + US-T002 (x1)  → 3 scans pour terminer
    TEST-A02 : US-T003 (x2)                 → 2 scans pour terminer
    TEST-B01 : US-T101 (x1) + US-T102 (x2)  → 3 scans
    TEST-B02 : US-T201 (x1)                 → 1 scan

  Regénérer le fichier :
    cd scripts\GenerateTestStockExcel
    dotnet run -- ..\

  Vérifier : http://localhost:5000/swagger

  2. Se connecter : superviseur@vectorys.local / Super123!
  3. Créer un inventaire (nom + date)
  4. Importer scripts/test-import-stock.xlsx

  Réponse attendue :
    emplacementsCrees : 4
    lignesStockImportees : 6
    assignationsParAgent : { "AG001": 2, "AG002": 2 }

  Vérification SSMS :

    FROM Emplacements e
    JOIN Utilisateurs u ON u.Id = e.AgentAssigneId
    WHERE e.Code LIKE 'TEST-%';

--------------------------------------------------------------------------------
ÉTAPE 5 — Vérification BDD après scans
--------------------------------------------------------------------------------
  SELECT e.Code, e.Statut, COUNT(s.Id) AS NbScans
  FROM Emplacements e
  LEFT JOIN Scans s ON s.EmplacementId = e.Id
  WHERE e.Code LIKE 'TEST-%'
  GROUP BY e.Code, e.Statut;
